# Salary Elevator

An interactive, single page landing site for **Full Stack Developer Salary in India: Fresher to Experienced Guide**.

Instead of a flat salary table, visitors ride a "salary elevator" through five career stages, compare four stack lanes (MERN, Java, Python and PHP), decode an offer letter with a small calculator, and jump to learning paths and further reading.

## Preview

Open `index.html` in any browser, or publish it with GitHub Pages.

## Features

- Interactive salary elevator with five career floors, animated range bar and a slider
- Four stack lane cards with indicative entry and experienced ranges
- Offer letter decoder that shows first year total, fixed monthly pay and the guaranteed versus variable share
- Learning shelf with two bootcamps and two courses, plus five blog reads
- Sticky header with mobile menu, scroll progress bar, back to top button, FAQ accordion and footer
- Fully responsive, keyboard friendly and respects reduced motion settings
- Palette: teal, sand, white and neon yellow
- Plain HTML, CSS and JavaScript. No build step and no dependencies

## Deploy on GitHub Pages

1. Push the files to a new repository named `full-stack-salary-elevator`.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Your page will be live at `https://YOUR-USERNAME.github.io/full-stack-salary-elevator/`.
